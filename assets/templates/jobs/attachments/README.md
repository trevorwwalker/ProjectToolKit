# Attachments

Screenshots, logs and other files that a job card links to.

- One folder per card number: `jobs/attachments/1031/` holds the files of card 1031 (any category).
- Link each file from the card, for example `[the error](../attachments/1031/error.png)` or the path in
  its Where or Evidence section.
- Keep files small: crop a screenshot, cut a log to the lines that matter. Binary types (images and
  the like) are already `binary` in `.gitattributes`.
- Attachments are not scopes or locks: any card may add a folder for its own number.
