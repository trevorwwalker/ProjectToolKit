# New plans

This folder holds only new plans: ones written with the developer and not yet turned into job
cards. Workers don't take work from here. When a plan is carded, it moves to `jobs/plans/`,
and to `jobs/archive/` when its last card is done. An empty folder means every plan is
scheduled.

Its master is ProjectToolkit's `assets/templates/ai/README.md`: fix that and run
`<ProjectToolkit>\bin\projecttoolkit.ps1 -Action jobs -Repo <this repository> -Update`.
